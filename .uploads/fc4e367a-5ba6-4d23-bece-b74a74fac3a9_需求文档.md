# 需求文档

## 1. 应用概述

- **应用名称**：学习打卡
- **应用描述**：面向学生的学习打卡类移动端App，通过阅读视频打卡与计算作业图片打卡两大核心场景，结合积分激励与虚拟/实物礼品兑换机制，帮助用户养成持续学习习惯。管理员可在后台灵活配置打卡规则（阶梯目标、作业页数、阅读时长、计算打卡上限等），配置实时同步至学员端。

## 2. 用户与使用场景

- **目标用户**：
  - 学员：需要培养阅读与计算习惯的学生用户。
  - 管理员：负责配置打卡规则、审核兑换申请的运营人员。
- **核心使用场景**：
  - 学员每日完成视频阅读学习并打卡；
  - 学员每日上传计算作业图片完成打卡；
  - 学员查看积分、连续/累计打卡进度并兑换礼品；
  - 管理员配置打卡阶梯、作业目标、阅读时长、计算打卡上限等规则；
  - 管理员查看当前规则并实时同步至学员端。

## 3. 页面结构与功能说明

### 3.2 功能说明

#### 3.2.1 登录/注册页

- 用户通过手机号+验证码完成注册与登录，注册时设置登录密码。
- 登录成功后进入首页。
- 系统首次启动时，需初始化一名管理员账号（手机号+密码），管理员登录后个人中心显示「管理员入口」。

#### 3.2.2 首页（打卡概览）

- 展示当前连续打卡天数、累计打卡天数、当前积分余额。
- 展示今日阅读打卡与计算打卡完成状态。
- 提供进入阅读打卡、计算打卡、积分中心、礼品商城、规则说明的入口。
- 管理员登录后额外显示「规则配置中心」入口。

#### 3.2.3 阅读打卡页

- 支持两种方式完成阅读打卡：
  - 录制学习视频：调用相机录制视频并上传；
  - 观看学习视频：选择已有视频进行观看。
- 单次打卡时长需达到管理员配置的「最少时长」（默认30分钟）方可提交成功，页面展示倒计时与已用时长。
- 打卡成功后记录本次打卡时长、视频文件、打卡时间，并增加对应积分。
- 同一用户每日仅可完成一次阅读打卡。

#### 3.2.4 历史视频回放页

- 以列表形式展示用户历史阅读打卡视频，包含打卡日期、时长、视频缩略图。
- 点击单条记录可在线回放对应视频。

#### 3.2.5 计算打卡页

- 支持拍照或从相册上传计算作业图片。
- 单次上传页数与每日打卡上限均按管理员配置执行（默认单次1页、每日2页）。
- 提交后由AI审核作业字迹质量以及对错，字迹工整清晰额外奖励1积分。
- 打卡成功后记录图片、审核结果、获得积分、打卡时间。

#### 3.2.6 计算打卡记录页

- 以列表形式展示用户历史计算打卡记录，包含日期、图片缩略图、审核结果、获得积分。
- 点击单条记录可查看图片详情。

#### 3.2.7 积分中心页

- 展示当前积分余额、累计获得积分、累计消耗积分。
- 以流水形式展示积分变动记录（来源：阅读打卡、计算打卡、字迹奖励、礼品兑换）。
- 展示当前连续打卡天数与阶梯奖励解锁进度（按管理员配置的阶梯目标动态展示）。
- 展示累计打卡页数与累计奖励解锁进度（按管理员配置的作业目标动态展示）。

#### 3.2.8 礼品列表页

- 分类展示虚拟礼品与实物礼品。
- 虚拟礼品：专属头像等装扮类礼品，标注所需积分与解锁条件。
- 实物礼品：标注所需积分、预算范围（100元以内）、剩余可兑换数量。
- 已解锁的礼品可点击兑换，未解锁的礼品展示解锁条件提示。

#### 3.2.9 虚拟礼品兑换页

- 用户选择已解锁的虚拟礼品后，确认兑换。
- 兑换成功后自动发放至用户账户（如头像自动应用或加入装扮库）。
- 扣除对应积分并生成兑换订单记录。

#### 3.2.10 实物礼品兑换申请页

- 用户选择已解锁的实物礼品后，进入兑换申请流程。
- 终极奖励（按管理员配置的最高阶梯解锁）支持自选商品：用户拍照上传心仪商品截图，填写商品名称、价格（100元以内）、购买链接或说明，发起兑换申请。
- 填写或选择收货地址（从地址簿选择或新增）。
- 提交兑换申请后生成订单，等待后台审核。

#### 3.2.11 规则说明页（学员端）

- 展示当前生效的打卡规则：阅读最少时长、计算每日上限与单次页数、作业累计目标与阶段分解、阶梯奖励列表。
- 仅可查看，不可编辑。
- 数据来源于管理员配置，实时同步。

#### 3.2.12 个人中心

- 展示用户头像、昵称、手机号、角色（学员/管理员）。
- 提供入口：我的打卡记录、我的兑换订单、收货地址管理、规则说明、设置。
- 管理员额外显示「规则配置中心」入口。
- 支持退出登录。

#### 3.2.13 我的打卡记录

- 按日期汇总展示阅读打卡与计算打卡记录。
- 支持按模块筛选查看。

#### 3.2.14 我的兑换订单

- 展示所有兑换订单，包含礼品名称、类型（虚拟/实物）、状态（待审核/已发放/已发货/已完成）、申请时间。
- 实物订单支持查看物流追踪信息。

#### 3.2.15 收货地址管理

- 支持新增、编辑、删除、设置默认收货地址。
- 地址字段：收货人、手机号、省市区、详细地址。

#### 3.2.16 规则配置中心（管理员）

- 仅管理员可访问，普通学员不可见。
- 包含四个子模块：打卡阶梯设置、作业打卡设置、阅读打卡设置、计算打卡设置。
- 所有配置项保存后立即生效，并实时同步至学员端。

#### 3.2.17 打卡阶梯设置

- 列表展示当前所有阶梯目标，字段：累计打卡天数、奖励名称、奖励说明、关联礼品（可选）。
- 支持新增、编辑、删除阶梯目标。
- 新增/编辑表单字段：
  - 累计打卡天数（正整数，1-3650）；
  - 奖励名称（必填，文本）；
  - 奖励说明（选填，文本）；
  - 关联礼品（选填，从礼品库选择）。
- 删除阶梯目标需二次确认。
- 阶梯目标按累计天数升序展示。

#### 3.2.18 作业打卡设置

- 配置累计需完成的作业总页数目标（正整数，1-10000）。
- 支持两种分解方式（二选一）：
  - 按每日目标：填写每日目标页数（正整数，1-100）；
  - 按任务阶段：可新增、编辑、删除多个阶段，每个阶段包含阶段名称（文本）与阶段页数（正整数，1-10000）。
- 切换分解方式时，原方式下的子配置清空并提示用户确认。
- 保存后学员端积分中心、规则说明页实时展示最新目标与进度。

#### 3.2.19 阅读打卡设置

- 配置单次阅读打卡最少时长（分钟，正整数，1-600）。
- 保存后学员端阅读打卡页倒计时与提交校验实时按新值执行。

#### 3.2.20 计算打卡设置

- 配置每日计算打卡页数上限（正整数，1-100）。
- 配置单次提交的计算作业页数（正整数，1-50）。
- 校验：单次提交页数不得大于每日上限。
- 保存后学员端计算打卡页实时按新值执行。

## 4. 业务规则与核心逻辑

1. **阅读打卡规则**：单次视频时长需≥管理员配置的「最少时长」方可提交成功；每日仅可完成1次阅读打卡。
2. **计算打卡规则**：单次上传页数与每日上限均按管理员配置执行；提交后由后台或AI审核字迹，工整清晰额外奖励1积分。
3. **打卡阶梯奖励**：阶梯目标由管理员自定义（默认7/21/30/60天），学员达到对应累计天数后解锁该阶梯配置的奖励或勋章，可关联礼品。
4. **作业累计奖励**：作业累计目标与阶段分解由管理员自定义，学员累计打卡页数达到目标或阶段后解锁对应奖励。
5. **积分规则**：阅读打卡、计算打卡、字迹奖励均产生积分；兑换虚拟/实物礼品时扣除对应积分。
6. **虚拟礼品发放**：兑换成功后系统自动发放至用户账户。
7. **实物礼品流程**：用户提交兑换申请并填写收货地址后，后台审核通过则发货，用户可在订单中查看物流追踪。
8. **自选商品兑换**：终极奖励自选商品需用户拍照上传商品截图，价格不超过100元，提交后由后台审核。
9. **打卡中断规则**：连续打卡天数在用户中断打卡后重置为0。
10. **每日打卡上限**：阅读打卡每日1次，计算打卡每日上限按管理员配置执行，超出后当日不可继续打卡。
11. **规则配置权限**：仅管理员可修改规则配置；普通学员仅可在规则说明页查看当前规则。
12. **规则实时同步**：管理员保存配置后，学员端的阅读打卡计时要求、计算打卡每日上限与单次页数、作业目标进度、阶梯奖励解锁进度均实时按新值展示与校验。
13. **管理员初始化**：系统首次启动时初始化一名管理员账号，后续管理员账号由该管理员维护。

## 5. 异常与边界情况

| 场景 | 处理方式 |
| --- | --- |
| 阅读视频时长不足配置的最少时长提交 | 提示时长不足，不允许提交 |
| 当日阅读打卡已完成再次提交 | 提示今日已完成，禁止重复打卡 |
| 计算打卡当日已达配置上限 | 提示今日打卡次数已用完 |
| 计算作业图片审核不通过 | 标记审核未通过，不发放字迹奖励积分 |
| 积分不足兑换礼品 | 提示积分不足，禁止兑换 |
| 实物礼品库存不足 | 提示库存不足，禁止兑换 |
| 自选商品价格超过100元 | 提示超出预算，禁止提交 |
| 自选商品截图上传失败 | 提示上传失败，允许重新上传 |
| 收货地址未填写提交实物兑换 | 提示需先填写收货地址 |
| 兑换订单审核被驳回 | 订单状态置为已驳回，退还对应积分 |
| 管理员配置数值非正整数或超出上下限 | 输入框校验拦截，提示合理范围 |
| 计算打卡单次页数大于每日上限 | 保存时校验拦截，提示单次不得大于每日上限 |
| 普通学员访问规则配置中心 | 拒绝访问，提示无权限 |
| 删除已被学员解锁的阶梯目标 | 已解锁学员保留奖励，新学员不再解锁该阶梯 |

## 6. 数据模型

### 6.1 用户表（user）

- 用户ID、手机号、密码、昵称、头像、角色（学员/管理员）、注册时间、当前积分、连续打卡天数、累计打卡天数、累计打卡页数。

### 6.2 阅读打卡记录表（reading_checkin）

- 记录ID、用户ID、视频文件地址、视频时长、打卡日期、创建时间。

### 6.3 计算打卡记录表（calculation_checkin）

- 记录ID、用户ID、图片地址、审核状态（待审核/通过/未通过）、字迹奖励积分、获得积分、打卡日期、创建时间。

### 6.4 积分流水表（points_log）

- 流水ID、用户ID、变动类型（阅读打卡/计算打卡/字迹奖励/虚拟兑换/实物兑换/审核退还）、变动积分、变动后余额、关联记录ID、创建时间。

### 6.5 礼品表（gift）

- 礼品ID、礼品名称、类型（虚拟/实物）、所需积分、预算金额（实物）、库存数量、礼品图片、解锁条件、状态。

### 6.6 兑换订单表（exchange_order）

- 订单ID、用户ID、礼品ID、礼品类型、订单状态（待审核/已发放/已发货/已完成/已驳回）、申请时间、审核时间、完成时间、备注。

### 6.7 自选商品申请表（custom_item_application）

- 申请ID、订单ID、用户ID、商品名称、商品价格、商品截图地址、商品链接、申请时间、审核状态。

### 6.8 收货地址表（address）

- 地址ID、用户ID、收货人、手机号、省、市、区、详细地址、是否默认。

### 6.9 物流追踪表（logistics）

- 物流ID、订单ID、物流公司、运单号、物流状态、最新轨迹、更新时间。

### 6.10 打卡阶梯配置表（ladder_config）

- 配置ID、累计打卡天数、奖励名称、奖励说明、关联礼品ID（可空）、创建时间、更新时间、状态（启用/停用）。

### 6.11 作业打卡配置表（homework_config）

- 配置ID、累计总页数目标、分解方式（每日目标/任务阶段）、每日目标页数（按每日方式时填写）、更新时间。

### 6.12 作业阶段配置表（homework_stage）

- 阶段ID、配置ID、阶段名称、阶段页数、排序、创建时间。

### 6.13 阅读打卡配置表（reading_config）

- 配置ID、最少时长（分钟）、更新时间。

### 6.14 计算打卡配置表（calculation_config）

- 配置ID、每日页数上限、单次提交页数、更新时间。

## 7. 验收标准

1. 用户可通过手机号+验证码完成注册与登录，登录后进入首页；系统首次启动可初始化一名管理员账号。
2. 学员可录制或观看视频完成阅读打卡，时长达到管理员配置的最少时长方可提交成功，打卡后积分增加且当日不可重复打卡。
3. 学员可在历史视频回放页查看并回放历史阅读打卡视频。
4. 学员可拍照或上传计算作业图片完成计算打卡，每日上限与单次页数按管理员配置执行，审核通过后字迹工整额外奖励1积分。
5. 学员累计打卡天数达到管理员配置的阶梯目标后，可解锁对应奖励或勋章。
6. 学员累计打卡页数达到管理员配置的作业目标或阶段后，可解锁对应奖励；终极奖励支持拍照上传商品截图发起100元以内自选商品兑换申请。
7. 学员可在积分中心查看积分余额、积分流水、连续与累计打卡进度，进度按管理员配置的目标动态展示。
8. 学员可在礼品商城兑换虚拟礼品，兑换成功后自动发放至账户。
9. 学员可在礼品商城兑换实物礼品，填写收货地址后提交申请，订单生成后可查看物流追踪。
10. 学员可在规则说明页查看当前生效的打卡规则，但不可编辑。
11. 管理员可在规则配置中心新增、编辑、删除打卡阶梯目标，并配置奖励名称、说明与关联礼品。
12. 管理员可配置作业累计总页数目标，并按每日目标或任务阶段两种方式分解目标。
13. 管理员可配置阅读打卡最少时长（分钟）。
14. 管理员可配置计算打卡每日页数上限与单次提交页数，单次不得大于每日上限。
15. 管理员保存配置后，学员端的阅读打卡计时要求、计算打卡每日上限与单次页数、作业目标进度、阶梯奖励解锁进度均实时同步展示。
16. 管理员配置数值输入仅允许正整数，超出合理上下限时拦截并提示。
17. 普通学员访问规则配置中心被拒绝，提示无权限。

## 8. 本期不实现功能

1. 多用户互动功能（如好友排行榜、互相点赞、社区分享）。
2. 学习课程内容的提供与教学功能。
3. 多管理员账号管理与权限分级（本期仅支持单一管理员）。
4. 规则配置的历史版本与回滚能力。
5. 积分过期、积分转赠等高级积分玩法。
